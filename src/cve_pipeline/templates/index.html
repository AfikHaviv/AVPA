CVE → LLM Exploit Pipeline

Educational use only — targets an isolated lab VM (e.g. Metasploitable2).

  1. 1. Fetch CVE Query the NVD API for the CVE's description, CVSS score and affected products.
  2. 2. Classify CVE Classify the CVE as server-side or client-side (network service, web application, browser/engine, document/file parser, ...) from its description, CVSS vector and affected products.
  3. 3. Generate & Explain Payload Prompt the open-source LLM to draft a PoC tailored to the CVE's classification, then to break it down and write an execution guide.
  4. 4. Mock Execute Validate the payload's CVE-specific markers and replay a simulated exploitation transcript tailored to the CVE's classification. No real network target, browser, or application is touched.
  5. 5. Save Artifacts Write the exploit script, breakdown, execution guide, classification and mock execution report to output/<CVE-ID>/.
